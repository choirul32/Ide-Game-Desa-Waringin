# Prompt Generate Image - Desa Waringin Mati (Stylized / Tidak Realistis)
### Game Horror FPS Android - Storyboard + Prompt Siap Copy-Paste

## Cara Pakai
1. Copy isi blok `Prompt` ke Midjourney / Leonardo / Flux / Bing Image Creator.
2. Keterangan Bahasa Indonesia di bawah tiap judul menjelaskan isi shot untuk storyboard / briefing artist.
3. Semua visual dibuat **stylized (tidak fotorealistik)** biar ringan, cocok untuk mood game Android dan tidak terlalu seram seperti foto asli.

## Master Style (wajib tempel di akhir setiap Prompt)
```
stylized dark illustration, Javanese horror game art, semi-realistic 3D render style, painterly texture, soft colors, atmospheric fog, cinematic lighting, mobile game concept art, NOT photorealistic, NOT photo, illustration --ar 16:9
```

## Negative Prompt (untuk Leonardo / SD / Flux)
```
photorealistic, photo, real human photo, ultra realistic skin, 8k photo, horror gore extreme, cartoon chibi, anime cute, bright daylight, modern city, western house, deformed hands, extra fingers, blurry
```
